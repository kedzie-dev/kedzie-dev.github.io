# Content-first blog design

Content and accessibility are primary, and the site should be as simple as its purpose allows. The reference personal and documentation sites inform direct navigation and prominent writing.

This decision supersedes the Atlas visual language and homepage map in ADR-0001. ADR-0002's collection URLs and aliases remain in force.

## Consequences

- The homepage lists recent writing and direct links to collections.
- Navigation and article layouts are text-first, with visible links and keyboard focus.
- Decorative map images, badges, appearance switching, and landmark navigation are removed.
- Search, code copy, Mermaid, incident simulators, and the Technology Evolution Map remain functional.
